# Light Chase 功能拓展说明（组员阅读版）

日期：2026-11-16；R2：本轮规则已由用户全部确认。用途：全员理解本轮要做什么，再按[开发分工与联调计划](../development/11_功能拓展分工与联调.md)开工。

**本轮先做功能，不做平衡调整。**移动倍率、效果时间、传送时间、道具数量和点位集中配置，先用能验证功能的测试值。本文是需求说明，不代表功能已经完成。

## 一、本轮增加什么

| 功能 | 玩家看到的变化 |
|---|---|
| 小道具 | 地图上出现道具，拾取后放进自己的道具槽，点击使用 |
| 两个道具槽 | 每人最多带两件，可以相同，也可以不同 |
| 小偷单向传送门 | 小偷从入口传到出口，变成双方都看得见的光球 |
| 门禁卡独立槽 | 小偷在地图拾卡后解锁通道，不占道具槽或任务物资槽 |
| 右上角小地图 | 双方查看整张地图、通道状态、自己的红点和各自可见的信息 |
| 警察独立瞄准 | 移动方向和手电方向分开 |
| 陀螺仪 | 游戏外选择开启；开启后转动手机瞄准，右侧按钮用来校准 |

原有取物、交付、撤离、标记、超时和结算继续保留。传送门光球是新增的公开效果，不改变落地后的正常视野规则。

## 二、小道具怎么用

| 角色 | 道具 | 功能 |
|---|---|---|
| 警察 | 光照强化 | 暂时扩大有效光照范围，画面和实际照射判定一起变化 |
| 警察 | 移动加速 | 暂时增加移动速度 |
| 小偷 | 移动加速 | 暂时增加移动速度 |
| 小偷 | 无敌护盾 | 清空正在累计的照射进度，暂时进入真隐身保护状态 |

- 每人有两个独立槽位，一件道具占一槽。同种道具也可以占两个槽。
- 点击哪个槽，就使用该槽的那一件；使用成功后该槽变空。
- 两槽都满时不能再捡，地面道具保留，不自动替换。
- 道具槽和小偷原本携带的任务物资分开，互不占位置。
- 使用由服务器确认，不能只在手机本地生效。
- 先做固定位置生成，后续再做有效候选点内随机出现。本轮不要求随机刷新或无限补货。

### 护盾特别说明

护盾复用现有“真隐身”的行为：警察看不到普通小偷角色，照射不能累计标记；现有真隐身的交互限制继续适用。

**清零的是本次尚未完成的照射进度，不是已经成功标记的次数。**例如已经被标记一次，护盾结束后仍然是一次。护盾不触发一次新的成功标记，也不自动增加后续免疫阶段。

护盾不会隐藏传送光球：只要正在传送，双方仍然看得见光球。

**已经真隐身或处于免疫时，也可以使用并消耗护盾。**刷新后的剩余真隐身时间 = max（护盾配置时长，当前剩余真隐身时间），不是两段时间相加，也不拿原始总时长重新计时。当前没有真隐身时，其剩余值按 0 算，包含从免疫切回真隐身的情况。

例如剩余真隐身 5 秒、护盾时长 3 秒，使用后仍剩 5 秒，但道具正常消耗；剩余 1 秒时使用同一道具则变为 3 秒。数字仅解释计算方式，不是最终数值。使用时照射累计仍清零，成功标记次数仍不变。

## 三、单向传送门怎么用

- 仅小偷能使用，警察不能使用。
- 开局通道未解锁，必须先拾取门禁卡并完成解锁；未解锁不能传送。
- 每条通道固定为“入口 → 出口”，不能从出口反向进入。
- 没有使用冷却；传送进行中不能再次启动传送。
- 每次成功启动传送都让警察知道，首版用提示和音效即可。
- 传送时普通人物隐藏，变为一个小光球，从入口直线飞到出口。
- **双方都能看到这次传送的光球，即使入口或出口不在普通人物视野里。**首版可在小地图同步显示，主画面显示当前镜头内的光球，不强制移动警察镜头。
- 到达出口后恢复普通人物与原视野规则；警察不能因此继续看到已经隐藏的小偷。

例子：小偷在 A 入口启动传送，双方看到光球 A → B。小偷到 B 后，光球消失；如果小偷此时不满足警察可见条件，警察只能知道这次传送到过 B，不能继续看到后续移动。

### 门禁卡与解锁显示

- 门禁卡先固定放在地图上，后续改成在有效候选点随机生成；不要求本轮做随机刷新。
- 小偷有单独的门禁卡显示/存储区域，独立于两个道具槽和任务物资槽。道具满槽不能阻止拾卡。
- 门禁卡槽最多携带一张卡；已经持卡时不能拾取其他卡，地面卡保留，不自动替换。
- 每张卡与一个通道一一对应，只能解锁对应通道。成功解锁后卡片销毁、卡槽清空，之后才能拾取下一张卡；错误通道或其他失败操作不消耗卡。
- 卡片和通道的颜色、符号等对应标记由 C 设计；A/B 通过稳定的卡 ID 与通道 ID 建立对应关系，不用颜色值判断能否解锁。
- 双方从开局就能在主地图和小地图看到通道出入口位置，未解锁为灰色，解锁后换为明确的启用色，并用图标或方向标识区分入口与出口。
- 解锁状态由服务器统一更新，两端显示一致，不暴露小偷拾卡时的隐藏位置或私有卡槽。
- 地图为两条单向通道，共四个不同端点，每通道一张对应卡；解锁本局永久有效。入口按住交互解锁，成功后必须松开重按才进入；出口不能解锁或进入。卡不能丢弃或替换，地图必须保证普通路径能抵达对应入口。

### 右上角小地图

双方对局界面右上角各有一块小地图，展示完整地图轮廓、墙体和公开通道出入口；自己的位置使用小红点表示。

- 所有公开通道均显示，按锁定/解锁状态换色；自己以外的图标与红点有明显区别。
- 任务点、地面物资、道具、门禁卡和对手，只显示服务器允许该玩家看到的信息，不因为小地图而额外获得隐藏位置。
- 对手从可见变为不可见时，小地图立即移除对应标记，不保留跟踪点；自己始终可定位。
- 传送光球为公开例外，双方小地图均显示；小偷传送中自己的红点跟随该光球进度，不停在旧入口。落地后移除公开光球，对手角色重新按可见性显示。
- 小地图不遮挡退出按钮、计时和操作区；地图按比例缩放，坐标与主地图一致。
- 当前工程已有左上角 `Minimap`，C 在其基础上移动到右上角并扩展，不另外复制一套地图显示系统。

## 四、警察怎么移动和瞄准

游戏外提供陀螺仪开关，对局内右侧只显示对应的一种控件。

| 模式 | 左侧操作 | 右侧操作 |
|---|---|---|
| 陀螺仪关闭 | 摇杆控制移动 | 瞄准摇杆控制手电 |
| 陀螺仪开启 | 摇杆控制移动 | 转动手机瞄准，右侧按钮负责校准 |

点击校准：把手机此刻姿态设为中立，同时把手电对齐行进方向。静止时取最近一次有效行进方向；本局还没移动则用出生朝向。

校准后，继续移动不会强制让手电跟着转，仍然可以边后退边照前方。设备不支持时，在游戏外说明并使用触控模式。小偷不增加这套警察专用瞄准控件。

## 五、用户已确认的具体操作规则

以下均已于 2026-11-16 由用户采纳，不再是临时默认；对应决策 E01–E12，工程字段见 [正式接口契约 R3](../development/02_接口契约.md)。

| 内容 | 已确认规则 |
|---|---|
| 拾取 | 道具、卡均靠近后按住原交互按钮，必须静止；移动/松开取消，各类型时长配置 |
| 目标选择 | 过滤可执行目标后取最近，同距离按稳定 ID；开始后锁定，完成后释放重按 |
| 光照与重复效果 | 光照只增距离；加速/光照同类有效时拒绝重复使用、不扣道具，二者可并存；护盾按 max 例外 |
| 原免疫尾段 | 护盾不赠送免疫；原标记免疫绝对截止不暂停、不延后，护盾结束后仅接尚未到期部分 |
| 保护中的交互 | 真隐身不能执行任何交互，含拾卡、解锁、进入；可移动及使用已有道具；免疫中可正常交互 |
| 传送 | 可携任务物资；过程禁移动、交互、道具和重复进入，不参与地表照射；效果及对局时间继续，落地不加保护 |
| 提示 | 每次成功启动给双方一次通道提示/音效，并显示公开光球；重复快照不重复播放声音 |
| 地面信息 | 双方全图公开道具、卡的位置及拾取后消失，允许据此推测路线；不公开私有背包/卡槽或隐藏人物坐标 |
| 同步顺序 | 道具先于移动和照射；有效护盾取消交互，加速/光照不主动取消；照射标记先于本步交互完成，终局不可复活 |
| 瞄准 | 松开右摇杆保持上次照射；左摇杆不带动手电；校准取当前/最近移动方向或出生朝向，同时重设姿态基准 |

## 六、怎样算功能完成

1. 两件相同或不同道具能各占一槽，满槽不能拾取，使用不会误消耗另一槽。
2. 光照强化改变真实照射范围；加速改变真实移动；结束后恢复。
3. 护盾清空当前照射进度，保护期间不产生标记，历史标记次数不变。
4. 警察不能使用传送门；小偷只能单向使用，无额外冷却；两端同时显示同一光球。
5. 每次传送警察都能收到提示；落地后不继续泄露隐藏的小偷位置。
6. 关闭陀螺仪显示右摇杆，开启显示校准按钮；移动和照明确实分离。
7. 新局、结算、退出后没有旧道具、旧强化、旧光球或旧姿态输入残留。
8. 在两台客户端联机完成以上功能，并记录真机陀螺仪测试结果；离线展示不能代替联机验收。
9. 小偷道具满槽时仍能拾卡到独立卡槽；警察不能拾卡或解锁；双方通道由灰色同步变为启用色，新局恢复锁定。
10. 真隐身或免疫时可消耗护盾，分别验证原剩余时间大于、小于、等于道具时长，不叠加、不缩短、不增加 marks。
11. 双方右上角小地图显示自己的红点、公开通道和允许看到的对象；隐藏对手无标记，传送光球可见，落地后不继续泄露。
12. 已持卡时不能再拾卡且地面卡保留；卡不能解锁错误通道且不消耗；匹配解锁成功后只销毁对应卡并清空卡槽，重复请求不消耗后来拾取的卡。

13. 解锁成功不自动传送，必须释放重按；真隐身不能拾卡、解锁或进入；允许携物传送，传送过程计时继续。
14. 原免疫剩余 4 秒时用 3 秒护盾，结束后只剩 1 秒免疫；护盾比原免疫长时不会被旧截止截断。
