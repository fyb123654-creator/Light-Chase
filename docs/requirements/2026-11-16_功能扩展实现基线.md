# 功能扩展实现基线

日期：2026-11-16。R2；状态：用户已确认全部操作规则及实现边界；不是功能完成报告。

本文件记录本轮道具、单向传送门、独立瞄准与陀螺仪需求。历史 V2/V3 示例不恢复为开发计划。当前阶段实现功能，不开展平衡讨论；倍率、持续时间、生成点和地图布局集中配置，后续调整。

## 1. 确认范围

- 警察道具：光照范围强化、移动加速。本轮只增加距离，角度不变；具体倍率配置化。
- 小偷道具：移动加速、无敌护盾；移除此前建议的静默装置。
- 道具首阶段固定出现在地图，后续改为从有效候选点随机生成。
- 双方各有两个独立道具槽，可同时存放相同或不同道具；每件占一槽、独立消耗，不能合成一个带数量的堆叠槽。两个槽都占用时拾取失败，地图道具保留。
- 地图包含两条单向通道、四个不同端点；每通道对应一张卡，解锁本局永久有效，新局恢复锁定；最终布局后置。
- 仅小偷可用，单向入口到出口；出口不能反向进入；无使用冷却。无冷却不等于允许传送期间重复启动。
- 每次实际启动传送均通知警察；首版可采用音效与屏幕提示，不要求复杂空间声学。
- 传送门 UI；穿越时人物变为小光球，沿入口到出口直线飞行，双方都能看到。
- 门禁卡必需：小偷独立卡槽，不占两个道具槽和任务物资槽；卡先固定生成，后续随机生成。通道开局锁定，双方可见出入口，灰色表示锁定，解锁后换色。
- 双方右上角小地图显示完整地图、公开通道状态、自己位置的小红点和各自获准看到的信息。扩展现有 Minimap，不复制第二套。
- 警察移动方向与光照方向分离。游戏外设置陀螺仪开关；右侧同一控制区域只显示一种形式：开启时为校准按钮，关闭时为瞄准摇杆。

## 2. 护盾

用户要求：清空当前累计标记进度，进入一段无敌状态，逻辑同成功标记后的真隐身。

- 有效使用时消耗所选槽的一件护盾，将照射累计进度清零。
- 复用 Protection.INVISIBLE 的真隐身语义：警察无法获得普通小偷角色的可见信息，照射不能累计标记。
- 不增加、不减少已成功标记次数，不调用会增加 marks 的成功标记路径。
- 原真隐身限制继续适用，例如禁止完成现有拾取、交付和撤离交互；不能仅在客户端画一个盾而仍允许服务端照射标记。
- 护盾持续时间独立配置；原标记免疫绝对截止不暂停、不顺延。护盾结束后仅接尚未到期的原免疫，不自动新增 IMMUNE。
- 已确认生效顺序：同一步中的合法道具使用先于照射累计；已经结束的对局不能使用护盾恢复。
- 两件护盾独立存在。处于真隐身或免疫时可以再次使用并消耗；新剩余真隐身 = max（道具时长，当前剩余真隐身），免疫时当前剩余真隐身为 0。不相加，不缩短，不以原始总时长替代剩余时长。
- 以服务器 tick 计算新截止：invisibleUntil = max（当前 tick + 道具配置 ticks，原真隐身截止 tick）。原标记免疫截止保持不变；计算保护状态时先检查真隐身，再检查免疫，不能用免疫截止截断较长护盾。

## 3. 单向传送状态与公开光球

- 状态为地表、传送中、到达；传送由服务器认可并记录起止 tick。
- 门禁卡解锁已经确认：每卡一一对应一个通道，成功解锁后卡销毁；独立卡槽最多一张，持卡时拒绝拾其他卡并保留地面卡。错误通道或失败操作不消耗卡。入口按住解锁后仅开门扣卡，释放重按才进入；出口不能进入或解锁，不增加冷却。卡不能丢弃或替换，所有卡对应入口须经普通路径可达。解锁状态双方公开，卡槽仅小偷私有。
- A/B 使用稳定卡 ID、通道 ID 判断与传递匹配关系；颜色或符号标记由 C 设计，不用美术颜色作为业务判定依据。重复请求不能消耗后来拾取的另一张卡。
- 传送中不重复接收进入请求；到达后不存在额外传送冷却。
- 光球位置由起点、终点和进度计算，沿直线移动；不把直线中途坐标交给地表墙体碰撞系统。
- 已确认：允许携任务物资传送；传送中暂停普通移动、交互和道具使用，不参与地表照射判定；落地恢复普通规则。传送中效果与对局时间继续计时，落地不新增保护；规则已确认，实现待完成。
- 公开传送数据与普通角色可见性分开：双方收到本次光球轨迹和进度，即使普通角色不可见也能绘制光球。
- 公开光球仅在本次传送期间有效；落地后立即恢复角色权限过滤，不能继续公开小偷后续坐标。
- 光球与真隐身同时存在时，按用户明确的“双方都能看到光球”显示传送效果；护盾不自动隐藏光球。
- 普通角色与传送光球不重复绘制；传送到达时清除旧移动插值，避免出洞后又被旧位置拉回。
- 地图加载检查入口和出口在有效地图内、出口可站立；无效配置在开局前报错。
- 新局、结算和离开对局清理传送、光球和提示状态。

## 4. 双道具槽

- 使用槽位 0 或 1 操作，各自保存一件道具实例；重复网络请求不能消耗另一件同类道具。
- 同类道具允许同时放在两个槽位，不能因为类型相同拒绝拾取。
- 拾取由服务器验证角色、距离、目标仍存在及空槽；槽满不删除地图实体、不自动替换。
- 使用成功后仅清空对应槽；效果持续与槽占用分离，已消耗道具不继续占槽。
- HUD 显示两槽内容、效果剩余时间及必要的不可用反馈；道具槽与原有任务物资携带状态分离。
- 倍率、持续时间配置化；加速/光照同类效果有效期间拒绝再次使用、不消耗，二者可同时生效；护盾例外。

## 5. 警察控制模式

| 游戏外设置 | 左侧 | 右侧 |
|---|---|---|
| 陀螺仪关闭 | 移动摇杆 | 瞄准摇杆 |
| 陀螺仪开启 | 移动摇杆 | 校准按钮 |

- 对局内不额外叠放另一套瞄准控件，也不增加独立的对局内陀螺仪开关。
- 校准将手机当前姿态记录为中立，同时把光照方向恢复到当前行进方向。
- 已确认：静止时取最近有效行进方向，本局尚未移动时取地图初始方向。
- 校准后继续独立瞄准，移动方向变化不自动覆盖光照方向。
- 触控与传感器最终产生同一种瞄准意图，由服务器用于实际照射判定；不能只旋转客户端画面。
- 不支持所需传感器时，在游戏外设置给出说明并回退触控模式。
- 新局重新初始化姿态基准；离开对局、后台和销毁时清理采样与旧输入。

## 6. 实现顺序与功能验收

先更新契约、规则与示例，再贯通网络、离线网关、Android 输入和显示；涉及线上字段或语义变更时升级协议版本，双方使用一致地图与配置。

1. 独立瞄准及两种互斥右侧 UI；校准在移动、静止和未移动情况下结果明确。
2. 固定地图道具与双槽；相同道具各占一槽，槽满拒绝，指定槽独立消耗，新局清空。
3. 护盾清空累计进度，真隐身期间不累计标记，历史标记次数不变，结束后恢复正常判定。
4. 单向传送、双方公开直线光球、警察提示；禁止出口反向使用，无额外冷却，传送请求不重复启动。
5. 联机与离线使用相同规则；公开光球不导致落地后的隐藏角色泄露；结算和新局无残留。
6. 真机验证陀螺仪开启、关闭、校准、设备不支持和生命周期处理。
7. 门禁卡拾取、独立存储、解锁同步换色、新局锁定恢复；满道具槽不影响拾卡。
8. 右上角小地图、自身红点、公开通道和光球、隐藏角色过滤；护盾在已有保护期间按 max 刷新。

本轮仅形成需求基线；未修改游戏代码，未执行以上功能验收，不宣称功能已完成。

## 7. 本轮操作规则收敛

2026-11-16 用户采纳 E01–E12，完整说明见[组员版第五节](2026-11-16_组员版功能拓展说明.md)及[决策表第 6 节](../development/04_决策与待确认事项.md)。

- 道具/卡靠近后按住拾取，必须静止；过滤合法目标后取最近，同距离按稳定 ID；开始后锁定、完成后释放重按。
- 真隐身禁止全部交互，含拾卡、解锁、进入，允许移动与使用已有道具；免疫可交互。
- 双方全图公开地面道具/卡及拾取消失，背包/卡槽私有；原任务物资权限不变。
- 道具可移动中使用，护盾取消交互，加速/光照不主动取消；道具先于移动/照射，照射标记先于交互完成。
- 松开瞄准摇杆保留照射方向，移动不带动手电；字段及逐步时序以 02 R3 为准。
