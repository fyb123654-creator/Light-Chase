## S0 实际复用记录

R01 为框架 API 调用，R02 为网络库 API 调用，均未修改上游库源码，也没有把 Fugitive 代码转换为 Java。本项目新增内容是模块边界、契约、权威规则原型、房间适配、测试地图、离线触摸展示及验证用例。

新增实际依赖：R08 Gson 2.11.0（JSON，game-data/client-network/server，Apache-2.0）；R09 SLF4J 2.0.16（日志，server 运行时，MIT）；R10 Error Prone annotations 2.27.0（Gson 传递依赖，Apache-2.0）；R11 JUnit 4.13.2 / Hamcrest Core 1.3（仅测试，EPL-1.0 / BSD-3-Clause）。完整版本链接和许可文本见 THIRD_PARTY_NOTICES.md、third-party/licenses。

验证：checkJvm 执行 23 项测试（含共享几何 5 项）；assembleDebug 生成 APK；installDist 生成服务器目录。Android assets/third-party 与 server 分发根目录包含声明/许可证。验证证据见 ../verification/2026-10-23_S0.md。骨架引入提交可用 git log --oneline -- README.md 查询，不预先编造提交号。

课堂说明可以展示：Gradle 中的依赖坐标 → Java 源码实际调用 → 模拟器运行 → 许可证和本登记。是否满足课程对“开源复现”的具体评分项，还需对照老师给出的标准，不能把使用框架等同于移植某个完整游戏。
