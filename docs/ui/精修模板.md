# 界面精修模板

大厅（Lobby）是这套界面语言的**参考实现**。其它页面按本文重做，不要另起一套。
改动任何页面前，先读第一节的七条硬规则——那是被反复纠正后定下来的东西。

---

## 零、术语

| 词 | 含义 |
|---|---|
| **格** | 1 个字符宽。以正文 19 号字体的 `M` 字宽为准（≈11 单位）。"3 格间距" = 约 33 单位 |
| **槽位** | 同"格" |
| **top 坐标** | 距屏幕上边的距离。代码里全部用这个，`UiTheme.yFromTop(top, h)` 换算成 GDX 的 y |
| **世界宽 `w`** | `ui.getWorldWidth()`，本机 20.2:9 ≈ 1616。右对齐一律用 `w - MARGIN - 宽度` |

---

## 一、七条硬规则

### 1. 均匀

**同一组内的间距必须全等。** 不是"看起来差不多"，是数值相等。

- 横向与纵向用**同一个**间距值（大厅：`GRID_GAP = 44`）
- 方框内部三段留白必须相等：上留白 = 标签与数值之间 = 下留白

```java
float pad = (BOX_H - capHeight(labelFont) - capHeight(valueFont)) / 3f;
labelTop = top + pad;
valueTop = top + pad * 2 + capHeight(labelFont);
```

- 推断出来的间距要**由代码算**，不要写死。例：`LEAVE ROOM` 与下划线的距离 = 「POLICE 名字与其下划线间距」的 **一半 × 1.3**。这样改上面的行距，下面自动跟着变。

### 2. 对齐

- **左右边距相等**：`MARGIN = 72`，左右都用同一个值
- **不同字号的两行要按中线对齐**，不是按顶对齐

```java
// 让 A（大字号）与 B（小字号）中线一致
float bTop = aTop + (capHeight(aFont) - capHeight(bFont)) / 2f;
```

- 同一列的标签、数值、说明都**水平居中在同一列心**（`ROLE_CX`、`boxCenter`）
- 顶部与底部的留白要对称（大厅：标题上沿 64 / 内容底部距下沿约 56）

### 3. 不准贴死

任何两个不同元素之间都要留气口，最小间距：

| 关系 | 最小值 |
|---|---|
| 文字 ↔ 它自己的下划线 | 1.5 格 |
| 线条 ↔ 内容 | 一条 `GRID_GAP`（44） |
| 元素 ↔ 屏幕边缘 | `MARGIN`（72） |
| 两行文字之间 | ≥ 0.8 × 字号 |

"贴着"= 视觉上粘连，即使数值上还有 1–2 单位也算贴死。

### 4. 动画

- **没有瞬时切换。** 所有状态变化都走插值（见第六节时长表）
- 统一用 `UiAnim.approach(current, target, dt, speed)`，帧率无关
- **先播动画，再发请求。** 按钮自己的动画没播完，不许调网关、不许换页

### 5. 白屏

所有换页/开局/离开都走同一套全屏过渡：

```
淡入白 0.65s → 保持 0.15s（在白幕下执行动作）→ 淡出白 0.65s
```

- 白幕画在**所有页面最上层**，换页那一刻屏幕必须是**纯白**，不许有菜单闪现
- 过渡期间 `tap()` 直接返回，禁止连点
- 按钮有动画时：动画播完 → 才进白幕

```java
startTransition(() -> gateway.setReady(!isSelfReady()));
```

### 6. 渐变

- 颜色变化、尺寸变化、透明度变化，**中间必须有帧**
- 值变了不能让文字"跳"成新内容 —— 旧值淡出、新值淡入（交叉渐变）
- 粒子/光束这类带 alpha 的图形，边缘必须渐隐，不允许硬边三角直接怼在屏幕上

### 7. 颜色

- 黑底 + 白字 + **一个**强调色（`ACCENT`）
- 强调色一屏最多两处，只用于：当前选择、危险动作、页面标识
- 灰阶三档（0.62 / 0.50 / 0.30）表达"次要"，不许再引入第四种灰
- 白底上的彩色文字必须中低饱和：对比度 ≥ 4.5:1，但不刺眼

## 二、画布与坐标

| 项 | 值 |
|---|---|
| 逻辑画布 | 1280 × 720 |
| 视口 | `ExtendViewport`：高度锁 720，宽度按设备比例伸展 |
| 超高屏（平板 16:10） | 世界高会 > 720，贴底元素统一加 `bottomShift()` |

```java
private float bottomShift() { return ui.getWorldHeight() - TouchController.UI_HEIGHT; }
```

## 三、字体

单一字族：**Nunito Sans SemiBold**（静态实例 + 拉丁子集，14 KB），`fonts/NunitoSans-SemiBold.ttf`。

| 用途 | 字号 | 字距 |
|---|---|---|
| 大标题 | 58 | 1.5 |
| 角色名 | 40 | 1.0 |
| 主按钮 / 页面小标 | 32 | 1.5 / 2.5 |
| 方框数值 | 30 | 0.5 |
| 正文（标签、说明、页脚） | 19 | 0.4 – 1.0 |

**字重只有一档**，不要靠"画两遍偏移"伪造加粗（试过，观感脏），用字号和颜色分层级。

**文字定位**：`BitmapFont.draw` 的 y 是**行顶**不是基线 → 用 `UiDraw.text(batch, font, s, x, top, color)`。
量字高用 `UiDraw.capHeight(font)`（从 `H` 的字形墨迹测得），不要用 `getCapHeight()`。

## 五、组件规范

### 1. 分隔线

粗细 **8**、**纯白**、两端**圆头**。用 `lobbyCapsule(shapes, x, top, w, h, color)` = 矩形 + 两端半径 `h/2` 的圆。

### 2. 信息方框（chip）

白色实心圆角块 + 黑字，2×2：

| 参数 | 值 |
|---|---|
| 高 | 76 |
| 间距 | `GRID_GAP = 44`（横竖同值） |
| 左起点 | `w × 0.54` |
| 圆角 | 九宫格（源图 96 / 半径 22） |
| 内部 | 三段等距（见规则 1） |

数值变化走**交叉渐变**（旧值 `1-fade` 淡出、新值 `fade` 淡入，3.4/s）。

### 3. 主按钮

| 参数 | 值 |
|---|---|
| 尺寸 | 228 × 64，圆角九宫格 |
| 底板 | `READY_BLUE`，文字纯白 32 号 |
| 位置 | 左下，`CTA_TOP = 560`，`x = MARGIN` |
| 按下 | **0.35s 整块洗白**（底与字一起变白，融进白幕），播完才进白屏 |
| 忙碌 | 底板 `LINE` 灰 + 灰字 + `WAITING...` |

### 4. 次级动作

纯文字 + 一条可长可粗的下划线，无底板：

- 文字 19 号 `LOBBY_GREY`，与主按钮**中线对齐**
- 下划线胶囊：常态 **5 槽位**宽、5 粗、`LOBBY_UNDER`；与文字间距 = 规则 1 的推导值
- 点击：5 槽 → 全宽、5 → 9 粗、灰 → `ACCENT`，文字 → 白；播完再进白屏

### 5. 角色卡

- 名字 40 号 + 说明 19 号，**都水平居中**
- 名字下胶囊下划线：常态 50% 名宽 / 5 粗 / `LOBBY_UNDER`；选中 100% 名宽 / 7 粗 / `ACCENT`
- 未选中 0.50 灰，选中纯白 —— 差值 ≥ 0.5，但未选中必须仍可读
- 图标在文字右侧，半径 30、距列心 232

### 6. 图标

只用 `ShapeRenderer` 基本图形，但必须有层次：**暗底 → 亮面 → 高光点**。
外圈一律加一层低透明柔边（alpha 0.2–0.3，半径 +4~6），否则黑底上边缘会切得生硬。

## 六、运动规范

| 场景 | 时长 / 速度 |
|---|---|
| 选中态切换 | 5.5/s |
| 手电熄灯 | 16/s |
| 手电转向 | 0.32s 线性 |
| 手电点亮 / 光束延伸 | 2.8/s |
| 主按钮洗白 | 0.35s |
| 次级动作下划线 | 涨 0.14s → 持 0.16s → 落 0.32s |
| 方框数值交叉渐变 | 3.4/s |
| 全屏白过渡 | 0.65s / 持 0.15s / 0.65s |

**三段式（手电，参考任何"先关再转向再开"的序列）**

```
0.00–0.14  熄灯        beamOn → 0，turn 锁 0
0.14–0.46  黑暗里转向   turn 0 → 1，beamOn 保持 0
0.46–0.90  点亮 + 延伸  beamOn 0 → 1，文字逐字变亮
```

反向离开同样三段：熄灯 → 转回 → 闲置光束延伸（`idleReach` 0 → 1，速度与点亮一致）。

---

## 七、交互规则

1. **不做 hover** —— 手机没有指针
2. **点击先给反馈，再发请求**
3. **状态只从"当前选择"推导**，不存副本
4. **未选中的东西也要能点**，不要因"对方占了"变死路
5. 过渡/动画期间**屏蔽输入**

---

## 八、踩过的坑（改之前必读）

| 坑 | 症状 | 处理 |
|---|---|---|
| **没开 GL 混合** | 带 alpha 的图形变成不透明：光锥成奶油三角、白幕盖死 | `shapes.begin` 之前 `glEnable(GL_BLEND)` + `glBlendFunc(SRC_ALPHA, ONE_MINUS_SRC_ALPHA)` |
| **形状通道先于文字通道** | 画在实心面板内部的线/点被盖住 | 面板内部元素放到 batch 通道、`uiRound.fill` 之后 |
| **`font.draw` 的 y 是行顶** | 文字整体偏低半字高 | 用 `UiDraw.text(..., top, ...)` |
| **`getCapHeight()` 偏大** | 位置算错约 8px（58 号） | 用 `UiDraw.capHeight(font)` |
| **可变字体只有默认字重** | 换字体后整界面变细 | `fontTools` 生成静态实例 + 子集化 |
| **`ExtendViewport` 在 16:10 撑高画布** | 底部元素浮空 | 加 `bottomShift()` |
| **`adb screencap` 有 200–300ms 延迟** | 0.2s 级动画抓不到，误判"没生效" | 时序写进注释，靠人工在模拟器上确认 |

---

## 九、套用到新页面的步骤

1. **列信息**：这页要显示哪几块，按重要性排序 → 定字号档位
2. **定网格**：先用 `MARGIN / GRID_GAP / RULE_H` 画两条白线，把版面切成上中下
3. **放组件**：chip / primary / 次级动作，不要新造控件
4. **接状态**：每个"当前值"配一个 `approach` 插值量
5. **接过渡**：会换页的按钮，动画结束后调用 `startTransition`
6. **跑检查**：`gradlew checkJvm :app:assembleDebug`，模拟器逐屏对照第十节

## 十、自检清单

**均匀**
- [ ] 横竖间距用同一个值
- [ ] 方框内部三段留白相等
- [ ] 推导出来的间距写在代码里，不是手填

**对齐**
- [ ] 左右边距相等
- [ ] 不同字号的行按中线对齐
- [ ] 同列元素居中在同一列心

**不贴死**
- [ ] 文字与下划线 ≥ 1.5 格
- [ ] 线条与内容 ≥ 44
- [ ] 元素离屏幕边 ≥ 72

**动画 / 渐变 / 白屏**
- [ ] 没有一帧跳变的状态
- [ ] 按钮动画播完才发请求
- [ ] 换页时屏幕是纯白，无菜单闪现
- [ ] 过渡期间输入被屏蔽

**颜色**
- [ ] 强调色 ≤ 2 处
- [ ] 白底彩字对比度 ≥ 4.5:1
- [ ] 灰阶只用三档

**其它**
- [ ] 最小字号 19，灰阶不低于 0.50
- [ ] 没有 hover 依赖
- [ ] 所有贴底元素都加了 `bottomShift()`
