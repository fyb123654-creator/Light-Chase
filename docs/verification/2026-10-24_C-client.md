### 2.1 本步范围

### 2.3 校验内容

- 页面只从 `RoomState.phase` 与 `ConnectionStatus.state` 推导，客户端不保存第二份阶段。
- 契约定义的 12 个错误码中，客户端可复现 6 个：替身返回 `CONNECT_FAIL`／`ROOM_FULL`／`ROLE_TAKEN`／`INVALID_PHASE`，本地校验产生 `ALREADY_CONNECTED`／`INVALID_ADDRESS`；均有可读提示。
- `PENDING`/`WAITING` 期间禁用角色、准备、返回大厅、退出控件；终态解除。
- 致命错误回连接页，并清空 session、room、view、result 与待处理控制。
- `MatchResult.winner` 为 `null` 时显示 `WINNER  NONE (both players left)` 与 `YOUR RESULT  NO DECISION`，不当成异常。

### 2.4 测试结果

`checkJvm` 178 项通过，0 失败。

### 2.5 已知边界与下一步

替身的 `SET_READY(true)` 返回 `SUCCEEDED`，真实 `LobbyServer` 返回 `INVALID_PHASE`（`LobbyServer.java:98`），联调前必须对齐；这不是 C 侧能修的。

## 4. 步骤 4A · 真实网关与局域网权限

### 4.1 本步范围

只做传输层接线、权限、插值、网络提示与代码拆分；不做真实快照渲染。

### 4.2 改动

| 文件 | 类型 | 说明 |
|---|---|---|
| `client-core/.../LightChaseApp.java` | 修改 | 双网关切换、权限前置、回调队列、网络提示；761 → 675 行 |
| `client-core/.../WorldRenderer.java` | 新增 | 从 `LightChaseApp` 抽出地图/光束/角色/小地图（162 行） |
| `client-core/.../ViewInterpolator.java` | 新增 | 100 ms 插值，纯 Java |
| `client-core/.../LanPermission.java` | 新增 | 局域网权限的平台抽象 |
| `android/.../AndroidLauncher.java` | 修改 | 注入替身与真实网关工厂；API 37 起申请 `ACCESS_LOCAL_NETWORK` |
| `client-core/src/test/.../ViewInterpolatorTest.java` | 新增 | 6 项插值测试 |

### 4.3 校验内容

- 每次 LAN 连接**新建**网关实例，旧 socket 与监听器不会串入新会话。
- 切换 `MODE` 时关闭旧传输并清空会话，避免两个传输同时回调。
- `ACCESS_LOCAL_NETWORK` 在**创建 socket 之前**校验；未授权时不建连接，提示写明是权限问题，不报成服务器宕机；API < 37 视为不需要。
- 网关工厂返回 `null` 时有守卫，不会把 `null` 当传输使用。
- 回调统一入队，渲染线程消费；插值窗口 100 ms。
- 对手不可见时**不插值**，第一帧即消失；换 `matchId` 清空插值历史。
- 旧传输在**四处**都会被关闭：错误路径、切换模式、重连前替换网关、`dispose`。
- 页面状态清零只有一处实现（`resetSession`），帧丢弃与插值清理成对（`dropFrame`）。

### 4.4 测试结果

`checkJvm` 195 项通过；`ViewInterpolatorTest` 6 项。

### 4.5 已知边界与下一步

`WebSocketClientGateway.error()` 只发 `onError`，**不改变 `ConnectionStatus`**（`WebSocketClientGateway.java:145`）。客户端因此必须自行关闭传输，否则状态停在 `CONNECTING`，客户端的 `ALREADY_CONNECTED` 守卫会把重连永久锁死。建议 B 在 `error()` 内落终态，或在契约 §12.1 写明。设备侧表现（权限弹窗、模式按钮、网络提示）本步未在模拟器上验证。

## 5. 步骤 5A · 替身脚本化两条胜利路径

### 5.1 本步范围

### 5.2 改动

| `client-core/src/test/.../FakeGatewayTest.java` | 修改 | 11 → 14 项，新增两条脚本与隐身不可见 |

### 5.3 校验内容

- 警察路径：普通 → 标记 1 → 隐身 1.5 s → 免疫 1 s → 普通 → 标记 2 → 标记 3 → `CAPTURED`，`winner = POLICE`，`result.marks = 3`。
- 小偷路径：拾取 M1（进度 > 0）→ 携带 → 交付 D1/D2/D3 → 出口开放 → 逃离 → `ESCAPED`，`winner = THIEF`。
- 携带中与已交付的物资**不在** `groundMaterials`；`originStatus.everPicked` 同步。
- 隐身时警察收到 `opponent = null`；免疫时可见但不再累计标记。
- 警察视图 `thief = null`，不泄露私有字段。
- 结算只发生一次。

### 5.4 测试结果

`checkJvm` 198 项通过；`FakeGatewayTest` 14 项。

时间类断言不踩边界：累计 `0.1 s` 不精确，断言点落在段中间而非整秒阈值。

### 5.5 已知边界与下一步

脚本按秒表推进，不含碰撞或判定逻辑；真实快照接入后只保留作回归样例。
